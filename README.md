## 1. Project objective
This portfolio project demonstrates beginner-level manual testing skills for a typical login form. It includes test scenarios, detailed test cases, a test execution sheet, and a bug report template.

## 2. Scope
In scope:
- Login form UI and field validation
- Valid and invalid credential handling
- Empty-field validation
- Password masking
- Basic keyboard interaction

Out of scope:
- Real payment or account data
- Security penetration testing
- Load/performance testing
- Backend/API testing

## 4. How to use this project
1. Select a permitted demo application or a local practice login page.
2. Record the application URL and test environment above.
3. Review `Test-Scenarios.xlsx` and `Test-Cases.xlsx`.
4. Execute each test case manually.
5. Record the actual result and status in `Test-Execution.xlsx`.
6. If you find a reproducible defect, create a record in `Bug-Report.xlsx`.
7. Save screenshots in the `Screenshots/` folder. Use filenames such as `BUG-001-invalid-password.png`.
8. Update this README with your real execution summary before sharing the repository.

## 5. Sample test coverage
- Valid credentials
- Invalid username
- Invalid password
- Both fields empty
- Username empty
- Password empty
- Password visibility / masking
- Keyboard navigation and form submission

## 6. Important reporting rule
The included cases are **test designs**, not evidence that a particular application passed or failed. Do not mark a test as Pass or report a bug until you execute it and observe the result. Expected behavior can differ by application; update the expected results to match its requirements.
